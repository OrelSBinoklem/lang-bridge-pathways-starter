# LangBridge — облегчённый исходный код

Независимая копия без истории Git, реальной базы, массовых учебных наборов и медиа. Некоторые тексты, примеры и инструкции по-прежнему встроены в код. Демо-данные расположены в demo/; автоматического импорта пока нет. Многие страницы ссылаются на отсутствующие картинки и аудио. Это исходная заготовка, не готовый курс и не замена резервной копии.

Для локального использования настройте собственную пустую базу и секреты, скопируйте .env.example в .env и запустите миграции только для новой БД. Приложение использует Laravel, Next.js и отдельный Node-шлюз бота. Пример подключения API для фронтенда — frontend/.env.example. Стандартный сидер намеренно пустой: заранее заданные пользователи и пароли не создаются.
